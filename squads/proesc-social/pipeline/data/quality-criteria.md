# Quality Criteria — Proesc Social Media Squad

> All content must meet these criteria before approval. Scores below 4/10 on any single criterion trigger automatic REJECT.

---

## Universal Criteria (All Platforms)

### 1. Brand Voice Alignment (1-10)
- [ ] Content speaks TO school managers, not ABOUT education
- [ ] Uses concrete data over generic adjectives
- [ ] Tone matches selected tone of voice from tone-of-voice.md
- [ ] No corporate jargon (disruptivo, ecossistema, otimização sem métrica)
- **Minimum to pass:** 7/10

### 2. Hook Quality (1-10)
- [ ] First sentence stops the scroll / compels action
- [ ] Creates curiosity, urgency, or personal relevance for school managers
- [ ] Delivers a specific promise or frames a specific problem
- [ ] Does NOT start with "Olá!" or "Ei, você sabia que..."
- **Minimum to pass:** 7/10

### 3. Value Delivery (1-10)
- [ ] Content teaches something actionable OR proves something surprising
- [ ] School manager can use this information immediately
- [ ] Includes at least one concrete number, data point, or real example
- [ ] Does not just say "use Proesc" without demonstrating the problem first
- **Minimum to pass:** 6/10

### 4. CTA Clarity (1-10)
- [ ] Has exactly one clear call-to-action
- [ ] CTA is specific (not "check out our site")
- [ ] CTA matches content stage (awareness → soft CTA; decision → direct CTA)
- **Minimum to pass:** 6/10

### 5. Accuracy (Pass/Fail — Hard Gate)
- [ ] All claims are factually accurate
- [ ] Statistics are correctly attributed
- [ ] No competitor information that could cause legal issues
- [ ] Proesc features described are actually available
- **Required:** Pass (any inaccuracy = automatic REJECT)

---

## Platform-Specific Criteria

### Instagram Feed
- [ ] Cover slide has bold title (max 20 words) that stops the scroll
- [ ] Each slide: 40-80 words, two-layer hierarchy (headline + supporting text)
- [ ] Background colors alternate (light/dark/accent)
- [ ] First 125 characters of caption work as standalone hook
- [ ] Caption ends with question or CTA
- [ ] 5-15 hashtags (mix niche + mid + broad)

### LinkedIn
- [ ] First 210 characters compel "see more" tap
- [ ] Written in first person
- [ ] 1-2 sentences per paragraph with line breaks
- [ ] No external links in post body
- [ ] 3-5 hashtags on last line only
- [ ] Ends with genuine question for comments

### YouTube Script
- [ ] Hook delivered in first 30 seconds
- [ ] Problem clearly stated by 60 seconds
- [ ] Clear visual cues / B-roll suggestions included
- [ ] CTA appears at natural pause point mid-video AND at end
- [ ] Script written for spoken delivery (contractions, natural rhythm)

### Facebook
- [ ] Opens with community-focused hook
- [ ] Includes engagement prompt (question or poll suggestion)
- [ ] Image/visual direction included
- [ ] Appropriate for parent and educator audience

### TikTok
- [ ] Hook in first 3 seconds (as stated in opening line of script)
- [ ] Problem → Solution structure in ≤60 seconds
- [ ] Sound/trend suggestion included
- [ ] Ends with clear "follow for more" or save prompt

## Scoring Rubric

| Score | Meaning |
|---|---|
| 9-10 | Publish as-is |
| 7-8 | Minor tweaks recommended but approvable |
| 5-6 | Revision needed — specific feedback provided |
| 3-4 | Major revision — structural issues |
| 1-2 | Reject — does not meet minimum standards |

**Automatic REJECT conditions:**
1. Hook score < 5/10
2. Accuracy gate = Fail
3. No CTA present
4. Brand voice violated (used competitor name negatively, made false claims)
5. Content inappropriate for school manager audience
